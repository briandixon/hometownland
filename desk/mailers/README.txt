Drop your mailer CSV exports in this folder.

Every .csv here is loaded when the Call Desk starts, and all of them are
searched at once -- on the primary number and all five alternate numbers.

If the same owner appears in two campaigns, the file with the most recent
modified date wins, so you quote the offer you actually mailed last.

Nothing in this folder is ever uploaded anywhere, and everything except this
README is ignored by git so it cannot reach the public website repository.
